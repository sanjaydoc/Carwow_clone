Get started in seconds

Works the same on Windows, macOS and Linux. All you need is Node.js 18+.

# 1. Clone & enter the project
git clone https://github.com/sanjaydoc/Carwow_clone.git
cd Carwow_clone

# 2. Install everything (root, server & client)
npm install

# 3. Seed the database with sample cars
npm run seed

# 4. Build the client and start the single server
npm start

# → open http://localhost:4000
